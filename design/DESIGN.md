# 工时 · 设计规范

本文是「工时」App 的唯一设计依据。以后加功能、改页面都按这里来。和代码不一致时，先改本文件再改代码，或者在本文件里说明原因。

## 1. 设计原则

1. **一天就是一条时间带。** 所有涉及时长的地方，都用 0–24 点横条加橙色时段来表达，不另外发明图形。
2. **橙色只给工作时段。** `#FF5B2E` 只用在：上班时段、缺卡提醒、当前标签的小圆点。按钮、标题、装饰一律不用橙色。
3. **一屏一个主角。** 今天页的主角是已工作时长，记录页是本周总时长，统计页是本月总工时。其余信息用灰色，字号也更小。
4. **单手、几秒钟。** 主操作放在拇指能够到的屏幕下半部，点击区域不小于 44×44px，主按钮高 64px。
5. **不写多余的字。** 不出现「示例」「提示」「说明」这类文字。状态用一两个字表达，例如「上班中」「补卡」。

## 2. 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#141414` | 主文字、大数字、主按钮底色、「现在」竖线 |
| `--mute` | `#777777` | 日期、单位、次要说明 |
| `--faint` | `#AAAAAA` | 未选中的标签、空状态文字 |
| `--line` | `#EEEEEE` | 分隔线 |
| `--track` | `#F1F1F1` | 时间带轨道、已完成按钮底色、按下时的底色 |
| `--accent` | `#FF5B2E` | 工作时段、缺卡、当前标签的小圆点 |
| `--bg` | `#FFFFFF` | 页面背景 |

- 遮罩：`rgba(0,0,0,.32)`。
- 危险按钮：文字用 `--accent`，描边用 `#FFD2C4`。
- 进行中的时段（已上班、还没下班）：橙色，`opacity:.55`。
- 缺卡：橙色 1.5px 虚线框，不用实心填充。
- 暂不做深色模式。以后要做时，`--ink` 和 `--bg` 互换，`--accent` 不变。

## 3. 字体

字体栈：`"PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui,sans-serif`。所有数字统一使用 `font-variant-numeric: tabular-nums`，保证数字跳动时宽度不变。

| 层级 | 字号 / 字重 | 其他 | 用在 |
| --- | --- | --- | --- |
| 主数字 | 56 / 800 | 字距 -1.5px，行高 1 | 今天页时长、统计页总工时 |
| 次主数字 | 40 / 800 | 同上 | 记录页本周总时长 |
| 主数字单位 | 20 / 600 | `--mute` | 紧跟主数字的「已工作」「小时」 |
| 数据值 | 20–22 / 700 | `--ink` | 三栏、统计宫格里的数值 |
| 区块标题 | 18 / 700 | | 月份标题、编辑面板标题 |
| 主按钮 | 18 / 700 | 白字 | 打卡按钮 |
| 正文 | 15 / 400 | | 列表日期、设置项 |
| 辅助 | 14 / 400 | `--mute` | 日期状态行 |
| 标签 | 12–13 / 400 | `#888` | 数值上方的名称、列表二级信息、底部导航 |
| 刻度 | 11 / 400 | `#999` | 时间带下方的 0 / 6 / 12 / 18 / 24 |

## 4. 空间与圆角

- 页面左右边距 22px，顶部 40px，再加上安全区 `env(safe-area-inset-top)`。
- 间距按 4 的倍数取值，常用 6 / 14 / 18 / 26 / 30px。
- 区块之间用 1px `--line` 分隔线，不用卡片阴影。

| 元素 | 圆角 |
| --- | --- |
| 时间带（44px 高） | 10 |
| 周时间条（14px 高） | 7（高度的一半） |
| 主按钮 | 14 |
| 实心按钮 | 12 |
| 描边按钮、输入框 | 10 |
| 底部编辑面板 | 顶部两角 20 |
| 圆形箭头按钮 | 20（40×40） |
| App 图标 | 108 网格上 24 |

## 5. 组件

### 时间带 `.band`
44px 高，底色 `--track`。橙色时段按 `上班分钟 / 1440` 定位，宽度为 `时长 / 1440`，最小 0.6%。「现在」竖线 2px 宽、`--ink`，上下各超出 6px。已下班时隐藏竖线。跨零点的班次，橙色时段画到 24 点为止。

### 周时间条 `.wk .r`
每行 34px 高，结构为「星期（34px 宽）+ 轨道 + 工时（40px 宽，右对齐）」。今天那一行的星期加粗、用 `--ink`。整行都可以点，点开就是编辑面板。

### 三栏数据 `.kv`
上方有一条分隔线，栏与栏之间用竖线隔开。上面一行是标签，下面一行是数值。「上班」「下班」两栏可以点，点了打开编辑；按下时数值变成橙色。

### 主按钮 `.main-btn`
固定在底部导航上方 20px，左右各留 22px，高 64px，`--ink` 底、白字。一天打完两次卡后变为 `.done` 样式：`--track` 底、`--mute` 字。

### 列表行 `.list .item`
上下内边距 14px，底部有分隔线。左边是「日期 周几」，下面一行小字写上下班时间和备注；右边是工时。缺卡时，右边改成虚线框里的「补卡」。

### 底部导航 `.tabs`
64px 高，加底部安全区。三个文字标签，当前标签加粗、用 `--ink`，上方有一个 4px 的橙色小圆点。不用图标。

### 编辑面板 `.sheet`
从底部滑出，每行 56px 高，系统原生的时间选择器右对齐。按钮顺序：删除（靠左）→ 取消 → 保存（实心）。

### 轻提示 `.toast`
出现在主按钮上方，黑底白字，圆角 20，显示 1.8 秒。内容只写结果，例如「上班 08:58」。

## 6. 动效

统一缓动曲线 `--ease-out: cubic-bezier(.2,.8,.2,1)`。系统开启「减少动态效果」时，所有动画关闭。

| 动效 | 时长 | 说明 |
| --- | --- | --- |
| 主按钮按下 | 120ms | 缩放到 0.95 |
| 打卡成功 | 360ms | 0.95 → 1.03 → 1 回弹，同时震动 20ms |
| 时段生长 | 700ms | 橙色时段宽度从旧值长到新值 |
| 「现在」线移动 | 600ms | 每 30 秒刷新一次位置 |
| 周时间条出场 | 500ms | 从左向右 `scaleX(0→1)`，每行比上一行晚 50ms |
| 切换标签 | 240ms | 淡入，同时上移 8px |
| 编辑面板 | 260ms | 从底部滑入，遮罩淡入 200ms |
| 轻提示 | 200ms | 淡入，同时上移 10px |

## 7. 状态与文案

| 状态 | 日期行 | 主按钮 | 第三栏 |
| --- | --- | --- | --- |
| 第一次使用 / 未上班 | `10月7日 周三 · 未上班` | 上班打卡 | 标准 8h |
| 上班中 | `… · 上班中` | 下班打卡 | 还差 1:18 / 超出 0:20 |
| 跨零点上班中 | `… · 上班中 · 昨天 23:00 起` | 下班打卡 | 同上 |
| 已下班 | `… · 已下班` | 今天已打完卡（灰色） | 同上 |
| 只有下班卡 | `… · 缺上班卡` | 上班打卡 | 标准 8h |

- 时长格式：今天页用 `时:分`（例如 `6:42`）；记录页和统计页用一位小数（例如 `8.2 h`）。
- 空状态只写一句话：「这个月还没有记录」。

## 8. 品牌

- 名称：**工时**。桌面图标名、manifest 的 name 和 short_name 都用这两个字。
- 图标：已选定 `design/brand.html` 中的方向 ②「工」字时间带：白底，黑色「工」字的上横和竖，下横换成 `#ECECEC` 轨道，中间一段 `#FF5B2E` 表示今天上的班。图标绘制在 108×108 网格上，主体图形放在中间直径 66 的安全圆内，这样被安卓裁成圆形、方形或水滴形都完整。由 `node design/make-icons.js` 生成：`icons/icon-192.png`、`icon-512.png`（圆角 24 的方块）、`icon-maskable-192.png`、`icon-maskable-512.png`（满底，字形缩到 0.8 倍）和矢量版 `icon.svg`。改图标只改这个脚本里的 `glyph`，然后重新运行。
- 字标：「工时」两字用 900 字重、字距 2px，后面跟一段 64×12 的时间带。深色和浅色底都可以用。
- 启动页：白底，图标居中，下方有一段 120×8 的时间带从左边长出来。App 加载完直接进入「今天」页。
- 主题色：manifest 和 `<meta name="theme-color">` 都用 `#FFFFFF`。
